The MacBook notch as a working tool

Cyclop is a free, open-source notch app for macOS. Invisible at rest; on hover it unfolds into a panel with a player, a file shelf, clipboard history, snippets, your next meeting, an offline translator and more.

What Cyclop puts in the notch

Ten tabs, plus Settings. Any of them can be switched off in Settings → Show in Panel, and off means two things: the icon leaves the rail, and the tab’s background work stops with it — the clipboard poll, the calendar watcher, the Now Playing helper, the rate fetch.

Music

Artwork, track, artist and a scrubber that actually seeks. The source is anything macOS itself can see: Apple Music, Spotify, or a video in a browser tab. Nothing to configure in the browser.

Shelf

Drag files into the notch and they wait there. Drag a card out and the file goes wherever it is dropped. ⌘-click selects several and drags them as a group. A screenshot copied to the clipboard is saved and lands here too — including one taken on an iPhone.

Clipboard

The last 40 copies. A click puts an entry back on the clipboard.

Snippets

A hand-kept list of what you are tired of retyping: an address, a phone number, an email. The same list is a plain JSON file you can edit in any editor.

Calendar

The next meeting a week ahead, how long until it starts, and a button that joins the call — Zoom, Meet, Teams and others. Meetings that overlap each get their own join button. Calendar access is asked for on a button press, not at launch.

Translate

Type on the left, the translation appears on the right — offline, using macOS's own translation, with no service and no account. English to Russian and back; the direction is taken from the script the text is written in.

Currency

An amount on one side, the other currency on the other; type into either. Rates come over the network from a public table of daily rates, once an hour and only while the tab is on.

Teleprompter

A script that scrolls under the camera at a speed you set. The notch is the one place on the screen a teleprompter belongs: the eyes stay on the lens instead of travelling to a window below it.

Notes

Scratch space. Hovering lands with the caret ready; blank notes sweep themselves out.

Utilities

A lock for wiping the keyboard and trackpad: the screen goes black and every press is swallowed until you hold Esc or − for 2 seconds, or a minute passes and it lifts by itself. It needs Accessibility — nothing less can stop keys from reaching macOS — and asks for it when you press the button, after an explanation.

How Cyclop is different

The notch category is crowded. These are the things Cyclop is measured on, all of them checkable in the source.

Zero dependenciesNothing but Swift, SwiftUI and AppKit. No package manager, no vendored frameworks. The whole thing is about 9 600 lines of Swift you can read over a weekend.
Nothing at launchTwo permissions, each asked only on a button press, after an explanation: Calendar, for the Calendar tab, and Accessibility, for the cleaning lock in Utilities. Switch either tab off and its permission is never asked for. No Screen Recording in any mode.
Any media sourceNow Playing is read from macOS itself, so a video in a browser tab works exactly like a music player — no browser extension, no per-app connector.
Offline translationTranslation runs on the device through macOS's own framework. No API key, no account, nothing leaves the machine.
Nothing collectedNo telemetry, no analytics, no crash reporting. The only network traffic is currency rates and, on the fallback path, Spotify artwork.
Actually small3.7 MB on disk, around 40 MB of memory, 0 % CPU at rest.

Install

  1. Download the latest .dmg from the releases page, open it and drag Cyclop into Applications.
  2. Launch it. It opens on the first try: since 0.8.0 every release is signed with a Developer ID and notarised by Apple, so there is nothing to allow and nothing to type.
  3. Updating works the same way: open the new image and replace the app. Coming from a version before 0.8.0, macOS may ask for the calendar permission once more, because the signature it was tied to has changed.
  4. Or build it yourself — the whole thing is one command, and no Xcode project is involved:
git clone https://github.com/akalikbergenov/cyclop.git
cd cyclop && ./Scripts/bundle.sh release

A build from source is ad-hoc signed and not notarised, so on any Mac but the one that built it the first launch goes through System Settings → Privacy & Security → “Open Anyway”. Releases do not have this step.

Questions

Does Cyclop work on a MacBook without a notch?

Yes. On a Mac without a physical cutout Cyclop marks a notch of its own at the top centre of the screen — a thin strip along the top edge at rest — and the panel opens from it the same way. It works on external displays too.

What permissions does Cyclop need?

Nothing at launch. Two permissions, each asked only on a button press, after an explanation: Calendar and Accessibility. Calendar is for the Calendar tab, and its dialog appears neither at launch nor when the tab opens, but when you press the button on a screen that explains why. Accessibility is for the keyboard and trackpad lock in Utilities: it lets an app see and swallow every key press in the system, and nothing less can stop keys from reaching macOS while you wipe them. Same terms — a button press after an explanation.

Use neither tab and Cyclop runs with no permissions at all; switch a tab off in Settings and its permission is never asked for. Screen Recording is not needed in any mode. The fallback player path, used only if the main one stops working, would also need Automation for Apple Music and Spotify.

One more thing macOS asks about on its own: a file placed on the shelf from Downloads, Documents or the Desktop, and only at the moment the shelf is opened.

Is Cyclop free? Is there a paid version?

Free, MIT-licensed, and there is no paid tier. No subscription, no ads, no accounts, and nothing is collected.

Which players does it control?

Anything macOS itself can see. Apple Music and Spotify work, and so does audio or video in a browser tab — YouTube included. Nothing has to be installed in the browser.

Does it send anything anywhere?

No telemetry and no analytics of any kind. The only network traffic is currency rates and, on the fallback path, Spotify artwork. Rates for the Currency tab come once an hour from cdn.jsdelivr.net, or latest.currency-api.pages.dev if that is unreachable, and only while the tab is enabled. Artwork is fetched only on the fallback player path, from the image address Spotify itself provides, or through open.spotify.com/oembed by track id. Everything else — clipboard, files, notes, snippets, scripts — stays on the machine.

Will macOS say the app cannot be verified?

No. Since 0.8.0 every release is signed with a Developer ID and notarised by Apple, so it opens on the first try. Only a build made from source is ad-hoc signed, and that one has to be allowed once in System Settings → Privacy & Security.

What does it cost in memory and battery?

About 40 MB plus a 14 MB helper process, and 0.0 % CPU at rest. What only draws stops when the panel folds — the clock behind the calendar, the position ticker behind the player. What has to keep watching — the clipboard poll, the calendar watcher, the Now Playing helper, the rate fetch — runs while its tab is enabled, and a tab switched off in Settings stops it.

Which macOS versions are supported?

macOS 15 and newer, Apple silicon only: releases are built for arm64. The floor comes from the translation framework the Translate tab uses.

Open source

Cyclop is built in the open under the MIT licence, and a good part of what is in it came from people who turned up in the first week: measurements from Macs the author does not own, a reverse-engineered fix for macOS 26 media control, and fixes to things nobody else had noticed. Issues and pull requests are welcome.
