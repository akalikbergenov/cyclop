# Удаление файлов вместе со снимками на полке

Переключатель «Удалять файл вместе со снимком» находится в разделе
«Скриншоты» и по умолчанию выключен. Значение
`trashScreenshotsOnRemoval` сохраняется в `config.json`; старые конфигурации
без этого ключа сохраняют прежнее поведение.

При включённой настройке крестик, «Удалить с полки» и «Очистить» отправляют
файлы распознанных скриншотов в Корзину. Обычные фото и документы лишь уходят
с полки, оставаясь на диске. При ошибке Корзины карточка остаётся, приложение
сообщает об ошибке. Автоматическое вытеснение за пределы 60 карточек и
удаление пропавших файлов при обновлении не вызывают удаление файлов.
Идентификатор файла запоминается вместе с карточкой и восстанавливается без
чтения файла при запуске. Если по тому же пути появился другой файл, при
удалении карточки этот новый файл не трогается.
Защитная обработка повторяющихся путей в сохранённой полке убирает все
карточки удалённого файла. Если файл остался на диске или удаление не удалось,
другие карточки этого пути сохраняются.

Распознаются:

- Снимки macOS с атрибутом `com.apple.metadata:kMDItemIsScreenCapture`.
- Новые копии из буфера, созданные `ScreenshotVault.save`, с собственной
  отметкой Cyclop. Как и прежде, это любая картинка из буфера, включая копию
  фотографии. Сохранённая копия удаляется отдельно от исходного фото;
  исходный файл остаётся на месте.
- Старые PNG с точным сгенерированным именем `Screenshot YYYY-MM-DD at
  HH.mm.ss.png` / `Снимок YYYY-MM-DD в HH.mm.ss.png` (включая суффиксы
  коллизий) внутри `~/Pictures/Cyclop` или прежней резервной папки
  `~/Library/Application Support/Cyclop/Screenshots`.

Расширение PNG/JPG само по себе не является признаком скриншота. Символические
ссылки не разыменовываются и не удаляются. Для файлов без отметки и вне
исторического соглашения об именах происхождение не угадывается: файл
остаётся. Историческое соглашение не доказывает происхождение намеренно
заменённого файла с тем же именем в папке Cyclop; в старой версии отдельного
реестра происхождения не было.

Тесты используют временные папки и собственную имитацию Корзины. Настоящие
снимки, исходные фото, настройки приложения и системная Корзина не меняются.

Проверка: `./Scripts/test.sh`, `./Scripts/bundle.sh release`,
`./Scripts/test-helper.sh` и проверка ключей локализации из `build.yml`.
Перед PR вручную проверить переключатель в обеих позициях, удаление снимка,
сохранность фотографии, «Очистить», перезапуск и ошибку удаления.

Проверено при реализации: 35 Swift-тестов прошли, включая замену файла под
карточкой до и после перезапуска. Сборка `./Scripts/bundle.sh release`, подпись
и `./Scripts/test-helper.sh` прошли; проверка переводов из CI и `plutil` — тоже.
Новый блок настроек отрисован отдельно на русском и английском с исходным
SwiftUI-кодом, без запуска основного Cyclop. Фактическое перемещение
пользовательского файла в системную Корзину вручную пока не проверялось.
