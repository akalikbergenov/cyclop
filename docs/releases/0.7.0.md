**Буфер обмена теперь открывается с клавиатуры — ⌘⌥V.**

Раньше до истории копирований надо было добираться курсором: довести до челки,
дождаться панели, найти вкладку, попасть в строку. Теперь по ⌘⌥V посередине
экрана появляется список, стрелки ходят по нему, Return вставляет запись прямо
туда, где стоит каретка. Руки с клавиатуры уходить не надо.

Список тот же самый — у истории по-прежнему один экземпляр, вкладка в панели
никуда не делась и показывает ровно то же.

| Клавиша | |
|---|---|
| `↑` `↓` | по истории, с обоих концов по кругу |
| `⇥` / `⇧⇥` | то же самое |
| `⇞` `⇟` `↖` `↘` | на экран за раз, в начало и в конец |
| `⌘1`…`⌘9` | сразу на одну из первых девяти записей |
| `⌥⌘V` ещё раз | на строку ниже, как ⌘⇥ ходит по переключателю приложений |
| `⏎` | в буфер и вставить |
| `⌫` | выбросить запись из истории |
| `esc` | закрыть, ничего не меняя |

Фокус у приложения, в котором ты печатал, список не забирает: панель
non-activating, поэтому впереди всё это время остаётся твое окно, и вставлять
некуда возвращаться.

**Одно новое разрешение — и то необязательное.** Нажать ⌘V в чужом приложении
значит синтезировать ввод, а это macOS разрешает только по галочке в
«Конфиденциальность и безопасность → Универсальный доступ». Диалог появляется
при первом выборе записи, не при запуске. Откажешься — сочетание всё равно
кладет запись в буфер, последний ⌘V просто останется за тобой. После галочки
macOS требует один раз перезапустить приложение; пока разрешения нет, в
меню-баре висит пункт «Разрешить автовставку…».

Само сочетание ⌘⌥V разрешений не требует вообще: оно регистрируется в оконном
сервере, который сообщает о нажатии именно этой комбинации и ничего больше о
том, что набирают.

**Если ⌘⌥V занято другим приложением**, оно останется за ним — Cyclop не
перехватывает сочетание силой и молча остаётся без него. Список тогда
открывается пунктом «Вставить из буфера» в меню-баре.

Режим «Скрывать содержимое» список уважает: строки закрыты точками, открыта
только та, на которой стоит выбор.
