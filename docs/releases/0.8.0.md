**Полка и буфер стали одним списком.**

Раньше скопированный текст попадал в одну вкладку, а скопированная картинка — в
другую. Разделение было техническим: строки жили в памяти, файлы на диске. Для
того, кто копирует, это была одна и та же вещь в двух разных местах, и половина
жалоб на ⌘⌥V сводилась к тому, что список не показывает картинки.

Теперь вкладка одна — «Буфер», и в ней всё: текст, ссылки, файлы, картинки,
видео. По ⌘⌥V открывается тот же список, с превью, и Return вставляет что
угодно: текст текстом, картинку картинкой, файл файлом. В Finder вставится файл,
в редакторе — само изображение.

Всё, что умела полка, осталось при файлах: превью от QuickLook, перетаскивание
наружу, ⌘-клик для группы, «Открыть», «Показать в Finder». Записи со старой
полки переносятся сами, при первом запуске.

**Появились настройки — вкладка с шестерёнкой, справа.**

| Настройка | |
|---|---|
| Хранить записей | 10…300, по умолчанию 60. Раньше было жёстко 40 и 60 |
| Хранить текст после перезапуска | По умолчанию выключено, и это осознанно: через буфер проходят пароли и коды, а писать их на диск приложение до сих пор не обещало. Файлы пишутся всегда — это ссылки на то, что и так лежит на диске |
| Сохранять скопированные картинки | То же, что было в меню-баре |
| Горячие клавиши | Сочетание для списка буфера — записывается нажатием. Плюс второе, для открытия самой панели; по умолчанию не назначено |
| Размеры | Ширина и высота раскрытой панели, ширина синтетической челки на Маках без выреза |
| Общее | Автозапуск, «Скрывать содержимое», и напоминание про Универсальный доступ, если автовставка ещё не разрешена |

Сочетание записывается как везде: нажать на поле, зажать модификаторы и нажать
клавишу. Esc отменяет, ⌫ убирает сочетание совсем. Без модификаторов не
записывается — иначе клавиша пропала бы во всей системе, включая то поле, в
котором её набирают. Запоминается физическая клавиша, а не буква: смена
раскладки сочетание не ломает.

Размер панели меняется на месте — панель пересобирается сразу, с задержкой в
треть секунды, чтобы удержанная стрелка не пересобирала её на каждый шаг.

**Попутно исправлено:** история копирований больше не пропадает при подключении
монитора. Хранилище раньше жило внутри панели, а панель пересобирается при любой
смене конфигурации экранов — вместе с ней исчезала и история. Теперь оно живёт
отдельно и переживает любую пересборку.
