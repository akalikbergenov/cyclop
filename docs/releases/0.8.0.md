Первый выпуск, который открывается с первого раза, — и рельс, с которого можно
убрать лишнее.

**Приложение подписано Developer ID и нотаризовано Apple.** Больше никакого
«Все равно открыть» и команды в Терминале при установке: образ открывается,
приложение перетаскивается в «Программы», и оно запускается. Подменённый файл
внутри бандла теперь не запустится вовсе — подпись запечатывает его целиком,
включая хелпер Now Playing, о чём и была речь в
[#20](https://github.com/akalikbergenov/cyclop/issues/20). Entitlement на
Apple-события и порядок подписи — из первого PR к проекту, @DontTrustMexD
([#1](https://github.com/akalikbergenov/cyclop/pull/1)).

При переходе с версии до 0.8.0 macOS может один раз заново спросить доступ к
календарю: у приложения сменилась подпись, а разрешение было привязано к ней.

**Любую вкладку можно выключить.** В настройках появился раздел «Показывать в
панели»: выключенная вкладка уходит с рельса и останавливает свой фон — опрос
буфера, наблюдатель календаря, процесс Now Playing, запрос курсов. Правило
сформулировалось в разговоре с @ispy4you о том, что телесуфлёр не всем нужен
([#43](https://github.com/akalikbergenov/cyclop/issues/43)): рельс — для
того, куда заглядывают на секунду между делом, а редкий режим живёт на нём
лишь пока тот, кому он не нужен, может его снять
([#80](https://github.com/akalikbergenov/cyclop/pull/80)).

**Конвертер валют.** Сумма слева, другая валюта справа, вводить можно в любое
поле; поиск по коду и названию, пара запоминается. Это единственная вкладка,
которая ходит в сеть: публичная таблица дневных курсов, раз в час, только пока
вкладка включена — SECURITY.md теперь перечисляет оба исходящих соединения
вместо обещания «ни одного». @ssharkexe
([#52](https://github.com/akalikbergenov/cyclop/pull/52)).

**Иконку в меню-баре можно убрать.** Переключателем в настройках или
⌘-перетаскиванием с бара; путь назад — повторный запуск Cyclop. «Выйти»
переехало в настройки, так что иконка перестала быть единственной дверью.
@ispy4you ([#84](https://github.com/akalikbergenov/cyclop/pull/84),
[#5](https://github.com/akalikbergenov/cyclop/issues/5)).

**Чёлка на внешнем дисплее перестала занимать весь бар.** С раздельными
пространствами macOS рисует иконки только на баре дисплея с фокусом, и внешний
монитор в момент замера считал свой бар пустым. Теперь «не измерил» значит
«не измерил», а не «пусто». @ispy4you
([#83](https://github.com/akalikbergenov/cyclop/pull/83),
[#66](https://github.com/akalikbergenov/cyclop/issues/66)).

Для тех, кто присылает правки: CI на PR из форка запускается сам, проверка
ключей перевода идёт первой и падает за секунды, у PR и issue появились
шаблоны, а правило «неделя без ответа — закрываем» теперь считает бот, а не
память мейнтейнера. Релиз собирает раннер по пушу тега. Открыты Discussions —
место обсудить идею до кода. Что такое расширения и почему узкие вкладки
пойдут туда, а не в ядро, записано в
[#91](https://github.com/akalikbergenov/cyclop/issues/91).
