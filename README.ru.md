# Cyclop

*[English](README.md) · Русский*

Челка MacBook как рабочий инструмент. Эта сборка форка — локальная панель на
SwiftUI/AppKit для полки файлов, буфера обмена, заготовок, перевода, заметок,
телесуфлёра и утилит. Music, Calendar и Currency исключены из приложения;
подробности — в [SECURITY.md](SECURITY.md).

[![Buy Me a Coffee](https://img.shields.io/badge/buy%20me%20a%20coffee-%E2%98%95-FFDD00?style=flat-square&labelColor=000000)](https://buymeacoffee.com/akalikbergenov)

Для этой сборки клонируй форк и собери приложение через `./Scripts/bundle.sh`.
Релизы исходного проекта содержат отключённые здесь функции.

## Что умеет

| Вкладка | Что делает |
|---|---|
| **Полка** | Перетащи файлы в челку — они лежат там, пока не понадобятся; тянешь карточку наружу и файл уходит куда нужно. Клик выбирает карточку, ⌘-клик — несколько, и тогда перетаскивается вся группа. Снимок экрана, сделанный в буфер обмена, сохраняется файлом и попадает сюда же — в том числе снятый на айфоне, если скопировать его там |
| **Буфер** | История последних 40 копирований, клик возвращает запись в буфер обмена |
| **Заготовки** | Ручной список того, что надоело набирать: почта, телефон, адрес. Добавляются кнопкой прямо в панели, удаляются крестиком на карточке; клик кладёт строку в буфер обмена. Тот же список лежит файлом в `~/Library/Application Support/Cyclop/snippets.json` и правится в редакторе, если так удобнее |
| **Перевод** | Слева пишешь, справа появляется перевод — сам, офлайн, средствами macOS. Английский переводится на русский, русский на английский; направление берётся из письменности. Языковые пакеты macOS не предустанавливает, поэтому первый раз их надо скачать: Системные настройки → Основные → Язык и регион → «Языки перевода…» |
| **Телесуфлёр** | Сценарий ползёт под камерой со скоростью, которую задаёте ползунком. Чёлка — единственное место на экране, которому телесуфлёр правда подходит: читаешь вплотную к объективу, и на записи это выглядит прямым взглядом, а не чтением с экрана. Пока текст идёт, панель держится открытой — сценарий читают, не касаясь трекпада |
| **Заметки** | Временные, в правом столбце иконок: быстро записать, вернуться, удалить или унести через буфер обмена. Наведение сразу даёт каретку, пустые заметки убирают себя сами |

Панель раскрывается по наведению на челку и сворачивается, когда курсор ушел.
Вкладки тоже переключаются наведением — но только если курсор на иконке
задержался: проходящий мимо ничего не переключает.
Во время перетаскивания файлов она раскрывается сама и сразу показывает полку.
Иконка в меню-баре — переключить панель, разом скрыть содержимое вкладок,
выйти. Саму иконку можно убрать: ⌘-перетащить с бара или переключателем в
настройках; повторный запуск Cyclop возвращает её обратно.

Любую вкладку можно выключить в **Настройках → «Показывать в панели»**.
Выключенная вкладка пропадает с рельса и останавливает свою фоновую работу.

## Требования

- macOS 15 или новее (вкладка «Перевод» работает на Translation.framework)
- Swift 6 toolchain (полный Xcode не нужен, хватает Command Line Tools)

На маках без челки приложение тоже работает: панель считает челкой область
180×24 pt по центру верхней кромки экрана.

## Сборка

```bash
git clone https://github.com/geraskinalekseysergeevich/cyclop.git
cd cyclop
./Scripts/bundle.sh          # swift build + сборка .app + ad-hoc подпись
open build/Cyclop.app
```

Иконка генерируется кодом, без графических редакторов:

```bash
swift Scripts/make-icon.swift "$PWD/Resources/AppIcon.icns"
```

## Установка

Локальная сборка подписана ad-hoc и не нотарифицирована. На другом Mac Gatekeeper
может потребовать **Системные настройки → Конфиденциальность и безопасность →
«Все равно открыть»**. Для корпоративного распространения задай
`CODESIGN_IDENTITY` с сертификатом Developer ID организации; нотарификация —
отдельный шаг.

Чтобы собрать DMG:

```bash
./Scripts/dmg.sh
```

Релизы исходного проекта содержат Music, Calendar и Currency, которых нет в этой
сборке. Используй приложение, собранное из этого форка.

## Разрешения

При запуске разрешения не запрашиваются. Вкладка Utilities может запросить
**Универсальный доступ**, только если нажать кнопку блокировки клавиатуры;
пока блокировка активна, приложение перехватывает системные нажатия клавиш.
Если функция не нужна, отключи Utilities в Settings. Доступ к файлам,
выбранным в системном диалоге, выдаёт macOS. В сборке нет разрешений
Apple Events или Calendar и не требуется запись экрана.

## Ограничения

- Полка ссылается на файлы, а не копирует их: если переместить оригинал, карточка
  исчезнет при следующем запуске. Исключение — снимки экрана из буфера обмена:
  они сохраняются в `~/Pictures/Cyclop` и не удаляются автоматически никогда,
  даже когда карточка уходит с полки. Чистит папку только пользователь: пункт
  «Очистить папку снимков» в настройках отправляет её содержимое в Корзину —
  тоже рукой, не по расписанию.
- Записи с типом `org.nspasteboard.ConcealedType` (менеджеры паролей) в историю
  буфера не попадают.
- Снимок с айфона приезжает через универсальный буфер обмена, поэтому требует
  того же, что и он: один Apple ID, включённые Bluetooth и Wi-Fi, Handoff и
  устройства рядом. И затирает буфер на маке — затёртое остаётся в истории
  «Буфера» в одном клике.
- Языки перевода macOS не предустанавливает — первый раз пакет придётся скачать
  через Системные настройки; панель говорит об этом и открывает нужный экран.

## Структура

```
Sources/Cyclop
├── main.swift                 точка входа, .accessory
├── App/
│   ├── AppDelegate.swift      иконка в меню-баре, автозапуск
│   └── Strings.swift          поиск строк в таблицах, текущий язык
├── Notch/
│   ├── NotchGeometry.swift    размеры челки и производные прямоугольники
│   ├── NotchPanel.swift       NSPanel над меню-баром
│   ├── NotchRootView.swift    hit-test панели + приемник drag&drop
│   ├── PointerWatcher.swift   опрос курсора: наведение и сквозные клики
│   ├── PanelState.swift       доля одного экрана: открыта, тянут, печатают
│   ├── NotchScreenPanel.swift панель, как она стоит на одном дисплее
│   └── NotchController.swift  одна модель, по панели на дисплей
├── Model/
│   ├── NotchViewModel.swift
│   └── PrivacyMode.swift      скрытие содержимого: разделы и раскрытия
├── Services/                  Calendar, Currency и Music исходники исключены из сборки
│   ├── ShelfStore.swift
│   ├── ClipboardStore.swift
│   ├── ScreenshotVault.swift  снимки из буфера на диск
│   ├── SnippetStore.swift     заготовки: чтение и запись snippets.json
│   ├── ConfigStore.swift      настройки: чтение и запись config.json
│   ├── Support.swift          ~/Library/Application Support/Cyclop
│   ├── DebouncedWrite.swift   запись на диск не чаще, чем нужно
│   ├── NoteStore.swift        временные заметки: notes.json
│   ├── Translator.swift       Translation.framework, направление по письменности
│   ├── TeleprompterStore.swift сценарий и то, где остановилось чтение
│   ├── ScreenshotFolderWatcher.swift  снимки, сохранённые на диск, на полку
└── UI/                        NotchShape, панели вкладок, тема
```

Исходники отключённых функций остаются в репозитории, но не компилируются в приложение.
